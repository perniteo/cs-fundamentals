1. 힙 정렬은 힙 트리 구조(최대 힙 트리나 최소 힙 트리)를 구성해 정렬을 하는 방법으로 여기서 힙이란 최소 값이나 최대 값을 빠르게 찾아내기 위해 완전 이진 트리를 기반으로 하는 트리를 말한다.
2. 기수 정렬은 원소의 기 캆을 나타내는 기수를 이용한 정렬 방법으로 정렬할 원소의 키 값에 해당하는 버켓(bucket)에 원소를 분배하였다가 버켓의 순서대로 원소를 꺼내는 방법을 반복하면서 정렬한다.
3. 기수 교환 정렬은 교환 정렬의 성질을 가지며 퀵 정렬과 유사하게 분할(partition)을 재귀적으로 반복하여 정렬하는 방법이다.
4. 병합 정렬은 여러 개의 정렬된 자료의 집합을 병합하여 한 개의 정렬된 집합으로 만드는 방법으로 분할 정복(divide and conquer) 기법을 사용한다.
