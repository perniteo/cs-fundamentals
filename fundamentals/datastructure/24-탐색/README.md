1. 탐색은 배열, 트리, 그래프, 파일, 데이터베이스, 인터넷 등 저장되어 있는 많은 자료들 중에서 어떤 성질을 만족하는 것을 찾아내는 작업을 말한다.
2. 탐색은 방법에 따라 탐색 대상의 키를 비교하여 탐색하는 비교 탐색 방식과 계수적인 성질을 이용한 계산으로 탐색하는 계산 탐색 방식이 있다.
3. 순차 탐색은 순서 화일의 첫 번째 레코드에서부터 마지막 레코드까지 차례로 비교해 나가면서 원하는 키 값을 갖는 레코드가 존재하는지 탐색하는 방법이다.
4. 색인 순차 탐색은 정렬되어있는 자료에 대한 색인 테이블(index table)을 추가로 사용하여 탐색 효율을 높인 탐색 방법이다.
5. 이진 탐색은 정렬(오름차순)되어있는 자료에 대해서 수행하는 탐색 방법으로 순환적으로 입력 데이터의 중간에 있는 레코드를 방문하여 찾고자 하는 특정한 키 값을 찾아가는 탐색 방법이다.
