1. 정렬은 자료를 키(key)에 따라 오름차순(ascending)이나 내림차순(descending)으로 재배열하는 것을 말하는 것으로 실행 방법과 정렬 장소에 따라 분류할 수 있다.
2. 삽입 정렬은 어떤 순서에 의해서 이미 정렬된 n개의 레코드(i번째 레코드 Ri의 키는 Ki)에 정렬되지 않은 새로운 레코드를 적당한 위치에 삽입하여 새롭게 정렬된 n+1개의 레코드를 갖는 화일을 생성하는 방법이다.
3. 선택 정렬은 제자리 정렬 알고리즘(in-place sort)의 하나로 화일에 있는 레코드를 연속적으로 선택하여 키 값에 따라서 각자의 적절한 위치에 배치하는 정렬 방법(push-down 정렬), 즉 전체 원소들 중에서 기준 위치에 맞는 원소를 선택하여 자리를 교환하는 방법이다.
