1. 쉘 정렬은 주어진 입력 화일을 여러 개의 부분 화일로 분할하여 분할된 각 부분 화일들을 독립적으로 정렬하는 방법으로 부분 화일들을 구성하기 위한 일정한 거리 h(증분)을 이용하며 증분만큼 떨어진 레코드들을 하나의 부분 화일로 구성하여 서로 비교한 후 교환하는 방식으로 정렬한다.
2. 퀵 정렬은 하나의 리스트를 피벗(pivot)을 기준으로 두 개의 비균등한 크기로 분할하고 분할된 부분 화일을 정렬한 다음, 두 개의 정렬된 부분 화일을 합하여 전체가 정렬된 화일이 되게 하는 방법이다. 퀵 정렬 시 순환 호출이 한번 진행될 때마다 최소한 하나의 원소(피벗)는 최종적으로 위치가 정해지므로, 반드시 끝난다는 것을 보장할 수 있다.
3. 칵테일 쉐이커 정렬은 양방향 거품 정렬 (bidirectional bubble sort) 또는 셰이커 정렬(shaker sort) 등으로도 불리는 버블 정렬의 변형된 정렬 방식을 말한다. 이 정렬 방법은 버블 정렬에 서의 비효율적인 부분을 개선한 정렬 방법으로 버블 정렬과는 다르게 매 라운드 마다 리스트의 순서(왼쪽과 오른쪽)를 바꾸면서 정렬하게 된다.
