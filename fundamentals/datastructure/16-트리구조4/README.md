1. 힙(heap)은 완전 이진트리의 하나로서 우선순위 큐를 위하여 만들어진 자료구조이다. 이러한 힙은 마지막 레벨을 제외하고 모든 레벨이 완전히 채워지기 때문에 배열에 저장하기 적합하고 힙을 구성하는 여러 개의 노드들 가운데서 가장 큰(작은) 키 값을 가지는 노드를 빠른 시간 내에 찾을 수 있다.
2. m-원 탐색 트리는 이진탐색트리의 확장된 자료구조이며 이진탐색트리보다 분기율이 높은 트리로서 트리의 노드가 m개 이하의 가지를 가질 수 있는 탐색 트리이다.
3. B-트리는 m-원 탐색 트리를 개선한 자료 구조로서 인덱스 구조를 구현하는데 가장 일반적으로 사용된다.
