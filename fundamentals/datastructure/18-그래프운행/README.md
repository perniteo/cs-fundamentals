1. 그래프 운행이란 비방향성 그래프 G=(V, E)와 V(E)에 속하는 정점 v가 주어졌을 때 정점 v로부터 시작하여 연결된 간선을 거쳐 도달할 수 있는 G의 모든 정점을 방문하는 것을 말한다.
2. 깊이 우선 탐색은 근노드(또는 다른 임의의 노드)에서 시작해서 다음 분기(branch)로 넘어가기 전에 해당 분기를 완벽(깊게)하게 탐색하는 방법이다.
3. 넓이 우선 탐색은 그래프 전체를 탐색하는 방법 중 하나로써 근노드(또는 다른 임의의 노드)에서 시작해서 인접한 노드를 먼저 탐색하게 되며 시작 정점으로부터 가까운 정점을 먼저 방문하고 멀리 떨어져 있는 정점을 나중에 방문하는 운행함으로써 노드를 넓게 탐색하는 방법이다.
