1. 피보나치 탐색은 이진 탐색과 같은 방법이나 비교 대상을 선정하는 기준이 피보나치 수열을 이용하는 방법이다.
2. 보간 탐색은 사전식 탐색과 유사한 방법으로 정렬된 리스트에서 범위를 줄여가며 탐색하는 알고리즘으로 비교 대상을 주어진 키와 일치하는 레코드 키가 있음직한 부분의 키를 선택해 나가는 반복을 수행하여 탐색하는 방법이다.
3. 블록 탐색은 순차 탐색과 이진 탐색을 혼합한 방법으로 찾고자 하는 키 값은 블록 내의 가장 큰 값과 비교하면서 요구되는 키가 들어있는 블록을 찾은 후 해당 블록 내에서는 순차 탐색이 이루어지는 방법이다.
