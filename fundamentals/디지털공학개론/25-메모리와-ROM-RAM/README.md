## 메모리
1. 메모리 번지 레지스터(MAR : memory address register)는 메모리 액세스시 특정 워드의 주소가 MAR에 전송되고, 메모리 버퍼레지스터(MBR : memory buffer register)는 레지스터와 외부 장치 사이에서 전송되는 데이터의 통로이다.
2. 메모리는 접근법에 따라 RAM(Random Access Memory 접근 시간이 어느 위치나 동일하게 걸리는 메모리 형태)와 SAM(Sequential Access Memory 원하는 위치에 도달하는데 일정한 시간이 경과되는 형태)로 구분된다.
3. 메모리는 기록 기능에 의해 RWM(Read and Write Memory 기록과 판독 두 가지를 모두 수행할 수 있는 메모리)와 ROM(Read Only Memory 판독만 가능한 메모리)로 구분된다.
4. 메모리는 기억 방식에 의해 정적 RAM(Static RAM : SRAM 주로 2진 정보를 저장하는 내부 Flip-flop으로 구성되며, 저장된 정보는 전원이 공급되는 동안에 보존. SRAM은 사용하기가 쉽고 일기와 쓰기 Cycle이 더 짧은 특징이 있다)과 동적 RAM(Dynamic RAM : DRAM 2진 정보를 충전기에 공급되는 전하의 형태로 보관하며, DRAM은 전력 소비가 적고 단일 메모리 칩 내에 더 많은 정보를 저장할 수 있으며, refresh회로가 필요하다)로 분류 된다.
5. 메모리는 휘발성에 따라 휘발성(volatile) 메모리(일정한 시간이 지나거나 전원이 꺼지면 기록된 내용이 지워지는 메모리 형태로 RAM은 모두 외부에서 공급되는 전력에 의해 정보를 저장하기 때문에 휘발성 메모리에 해당)와 비휘발성(non-volatile)메모리(전원이 차단되어도 기록된 정보가 유지되며, 자기코어나 자기디스크 메모리가 해당. 디지털 컴퓨터가 동작하는데 필요한 프로그램을 저장하는데 사용)로 구분된다.
