1. 위험 식별
   - 알려지거나 예측 가능한 위험 요소를 파악하는 작업으로, 위험 항목 점검목록을 작성하여 활용한다
2. 위험 회피(risk svoidance)
   - 위험 관리에 대한 최상의 전략으로 위험이 발생될 것을 예상하고 회피하는 것이다.
3. 위험 감시(risk monitoring)
   - 위험 요소 징후들에 대하여 계속적으로 인지하는 것이다
4. 유지보수 (maintenance)
   - 개발된 소프트웨어의 품질을 항상 최상의 상태로 유지하기 위한 것으로, 소프트웨어 개발 단계 중 가장 많은 노력과 비용이 투입되는 단계이다.

7. 신뢰도 측정
   - MTBF(Mean Time Between Failure) : 평균 고장 간격, MTBF = MTTF + MTTR
   - MTTF(Mean Time To Failure): 평균 가동 시간,
   - MTTF = ( 가동시간1 + 가동시간2 +…+ 가동시간n )/n
   - MTTR(Mean Time To Repair): 평균 수리 시간
   - MTTR = ( 고장시간1 + 고장시간2 +…+ 고장시간n )/n
   - 가용성(신뢰도)측정 : 정상적으로 가동된 시간의 비율
   - MTTF / MTBF X 100%
8. 신뢰도 요소(RAS)
   - 신뢰도(Reliability), 가용도(Availability), 보전도(Serviceability)
