1. 추상화
   - 사물이나 표상을 어떤 성질, 공통성, 본질에 착안하여 그것을 추출하여 파악하는 것이라 정의한다. 즉, 객체에서 공통된 속성과 행위를 추출 하는 것이다.
   - 추상화는 불필요한 정보는 숨기고 중요한 정보만을 표현함으로써 프로그램을 간단하게 만드는 것이다.
   - 공통의 속성과 행위를 찾아서 타입을 정의하는 과정이다.
2. 캡슐화
   - 서로 연관있는 속성(데이터)과 기능(함수)들을 하나의 캡슐(capsule)로 만들어 데이터를 외부로부터 보호하기 위해 데이터와 데이터를 처리하는 함수를 하나로 묶는 것이다.
3. 정보 은닉
   - 캡슐화에서 가장 중요한 개념으로 다른 객체에 자신의 정보를 숨기고 연산만 을 통하여 접근을 허용하는 것이다.
   - 각 객체의 수정이 다른 객체에게 주는 고려되지 않은 영향(side effect)을 최소화하는 기술이다.
4. 상속
   - 부모의 성질이 자식에게 물려진다는 생물학적 개념을 소프트웨어공학 기법에 도입한 것으로 프로그램을 쉽게 확장할 수 있도록 도와주는 수단으로, 객체 지향 패러다임에서만 구현이 가능하다.
   - 상세화 : 부모(super) 클래스의 속성을 상속받아 자식(sub) 클래스에서 실체화 한다.
   - 일반화 : 자식 클래스의 공통 특성을 추출하여 부모 클래스로 추상화 하여 정의한다
5. 다형성
   - 메시지에 의해 객체(클래스)가 연산을 수행하게 될 때 하나의 메시지에 대해 각 객체(클래스)가 가지고 있는 고유한 방법으로 응답할 수 있는 능력이다.
   - ‘다형성’은 여러 가지 형태를 가지고 있다는 의미로 하나의 메시지에 대해 여러 가지 형태의 응답이 있다는 것을 의미한다.
