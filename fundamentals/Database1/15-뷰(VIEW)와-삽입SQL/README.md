1. 뷰는 복잡한 질의를 간단하게 표현하는 수단이며 뷰를 정의하는 SQL문은 ‘CREATE VIEW 뷰이름 AS SELECT문’ 이고 하나 또는 하나 이상의 테이블이나 뷰로부터 정의될 수 있다.
2. 뷰에서 변경(삽입, 삭제, 갱신) 연산은 제한적이고 복잡한 질의를 간단하게 표현하는 등의 장점과 뷰의 정의를 변경할 수 없다는 등의 단점이 있다.
3. 트리거는 명시적인 이벤트가 발생할 때마다 DBMS가 자동적으로 수행하는 사용자가 정의하는 프로시저이다.
4. 트리거를 이벤트-조건-동작(ECA) 규칙이라고 부른다.
5. 일반 호스트 언어의 프로그램에 SQL문을 삽입하여 데이터베이스를 접근하는 부분을 처리하는 것이 삽입 SQL이다.
6. MS SQL의 ESQL/C는 정적 SQL문과 동적 SQL문을 모두 지원한다.
