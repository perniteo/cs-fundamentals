1. 논리적 설계 단계에서는 ER 스키마를 관계 데이터 모델의 릴레이션들로 사상한다.
2. 최종 사용자 릴레이션으로 사상할 대상은 ER 스키마에서 개체와 관계타입, 속성의 유형에 따라 사상하는 방법이 다르다.
3. ER 모델을 릴레이션으로 사상하는 7단계 알고리즘은 정규 개체타입과 단일값 속성, 약한 개체타입과 단일값 속성, 다중값 속성, 2진 1:1 관계타입, 정규와 약한 개체타입과, 2진 1:1, 2진 1:N, 2진 M:N, 3진 이상의 관계 타입으로 구분하여 릴레이션으로 사상시키는 방법이다.
4. 사례로 기업의 ER 스키마에 7단계의 알고리즘을 적용하여 릴레이션들로 사상하여 논리적 설계 능력을 향상하고자 하였다.
