1. 데이터베이스 보안은 권한이 없는 사용자로부터 데이터베이스를 보호하는 것이다.
2. 데이터베이스 보안에는 물리적 보호, 권한 보호, 운영 보호가 있다.
3. 서로 다른 객체들에 대해서 다양한 권한들이 존재하는데 임의의 객체에 대한 특정 권한을 Grant문을 사용하여 다른 사용자나 역할(Role)에 권한을 허가할 수 있다.
4. 허가된 권한을 취소하기 위해서 Revoke문을 사용한다.
5. 허가할 수 있는 연관된 권한들의 그룹으로 사용자들에 대한 권한 관리를 단순화하기 위해 Role을 사용한다.
6. MS SQL의 보안 메커니즘은 몇 개의 역할(Role)이 미리 정의되어 있고 데이터베이스에 있는 객체의 모든 사용 권한과 소유권은 사용자 계정에 의해 제어된다.
