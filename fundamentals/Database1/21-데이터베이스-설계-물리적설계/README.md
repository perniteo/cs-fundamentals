1. 물리적인 설계 단계에서는 논리적인 설계의 데이터를 보조 기억장치 상의 파일로 사상하는 것으로서 질의와 트랜잭션을 분석하고 데이터에 대한 효율적인 접근을 제공하기 위해 저장 구조와 접근 방법을 다룬다.
2. 디스크는 데이터베이스를 장기간 보유하는 보조 기억장치이고 DBMS의 성능은 주로 디스크 입출력 연산의 횟수에 좌우된다.
3. 한 릴레이션을 구성하는 레코드들의 모임이 파일이라고 부르는 블록들의 모임에 저장된다.
4. 파일 조직은 파일 내의 데이터를 보조 기억장치에서 블록과 레코드를로 배치하는 것이다.
5. 파일 조직의 유형으로서 히프 파일, 순차 파일, 인덱스된 순차 파일, 직접 파일이 있다.
6. 인덱스된 순차 파일은 인덱스를 통해서 임의의 레코드를 접근할 수 있는 파일이다.
