1. 트랜잭션은 데이터베이스 응용에서 하나으 논리적인 연산을 수행하는 데이터베이스 연산들의 모임이다.
2. 트랜잭션은 원자성(Atomicity), 일관성(Consistency), 고립성(Isolation), 지속성(Durability)을 만족한다.
3. 트랜잭션은 성공시 Commit을 수행하고 실패시 Rollback을 수행한다.
4. 동시성 제어 기법은 다수의 트랜잭션들을 동시에 수행하는 환경에서 트랜잭션들 간의 간섭이 생기지 않도록 한다.
5. 회복은 데이터베이스를 장애 발생 이전의 상태(Consistent State)로 복원하는 것을 말한다.
6. 데이터베이스 응용기술에는 데이터 웨어하우스, OLAP, 데이터 마이닝, 객체지향 데이터베이스 등이 있다.
