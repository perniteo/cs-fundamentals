1. 릴레이션을 분해하면 중복이 감소되고 갱신 이상이 줄어든다.
2. 제1정규형은 릴레이션 R의 모든 속성이 원자 값만을 가진다.
3. 제2정규형은 릴레이션 R이 제1정규형을 만족하면서 후보키에 속하지 않는 모든 속성들이 R의 기본키에 완전하게 함수 종속한다.
4. 제3정규형은 릴레이션 R이 제2정규형을 만족하면서 키가 아닌 모든 속성이 릴레이션 R의 기본키에 이행적으로 종속하지 않는다.
5. BCNF는 릴레이션 R이 제3정규형을 만족하고 모든 결정자가 후보키이다.
6. 역정규화는 검색 질의들의 수행 속도를 높이기 위해서 이미 분해된 두 개 이상의 릴레이션들을 하나의 릴레이션으로 만드는 작업이다.
