1. 데이터베이스 설계는 특정 조직에서 필요로 하는 데이터베이스 응용을 지원할 수 있도록 데이터베이스의 논리적인 구조와 물리적인 구조를 설계하는 것이다.
2. 데이터베이스 설계는 요구사항 분석, 개념적 설계, 논리적 설계, 스키마 정제, 물리적 설계로 이루어진다.
3. ER 모델은 실 세계를 개체, 속성, 개체들간의 관계로 표현하는 개념적 데이터 모델이다.
4. 개체(Entity)는 독립적으로 존재하면서 고유하게 식별이 가능한 실세계의 객체로서 요구사항 명세에서 명사로 식별된다.
5. 속성(Attribute)은 하나의 개체와 연관되는 특성으로 요구사항 명세에서 명사나 형용사로 식별된다.
