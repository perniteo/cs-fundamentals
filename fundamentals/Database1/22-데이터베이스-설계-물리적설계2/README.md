1. 단일 단계 인덱스는 데이터 파일에 대해 하나의 인덱스 파일을 구성하는 것으로 기본 인덱스, 클러스터링 인덱스, 보조 인덱스가 있다.
2. 일부 키 값에 대해서만 인덱스에 엔트리를 유지하는 인덱스는 희소 인덱스이고, 각 레코드의 키 값에 대해서 인텍스에 엔트리를 유지하는 인덱스는 밀집 인덱스이다.
3. 다단계 인덱스는 단일 단계 인덱스를 디스크 상의 하나의 순서 파일로 간주하고 단일 단계 인덱스에 대해서 다시 인덱스를 정의한다.
4. SQL에서 인덱스의 정의는 CREATE INDEX 구문을 사용한다.
5. 인덱스는 장점과 단점이 있으며 인덱스 선정시 기본키, 외래키, 속성에 속한 상이한 값들의 개수, 갱신빈도 등을 고려한다.
