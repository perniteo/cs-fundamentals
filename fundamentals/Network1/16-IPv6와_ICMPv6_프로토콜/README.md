● 16강에서는 네트워크 계층의 차세대 프로토콜인 IPv6와 ICMPv6의 개념과 기능에 대하여 학습 하였습니다.
1.  주소의 길이는 128비트로서, 충분한 주소를 할당받을 수 있기 때문에 주소 부족 현상이 일어나지 않을 것이다.
2. IPv4에서 IPv6으로의 전환 기술은 IPv4 네트워크망과 IPv6 네트워크망 간에 주소 변환기를 이용하여 IP를 상호 연동시키고, 게이트웨이를 이용하여 IPv4와 IPv6 주소 체계를 호환하는 기술이다.
3. 전환 기술은 응용 계층 게이트웨이 방식, 전송 계층 릴레이 방식, 네트워크 계층 헤더 변환 방식이 있다.
4. 인터넷 제어 메시지 프로토콜 버전6(Internet Control Message protocol version 6)는 버전 4의 목적과 방법과 동일하다.
