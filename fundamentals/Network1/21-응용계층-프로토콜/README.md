● 21강에서는 응용 계층에서 각종 프로토콜의 기능에 대하여 학습 하였습니다.
1. FTP는 파일 전송 프로토콜로 TCP/IP 네트워크 환경이나 인터넷에서 많은 사람과 파일을 공유할 수 있는 가장 일반적인 방법을 제공한다.
2. HTTP는 클라이언트의 웹 브라우저가 서버에 웹 서비스를 요청하면 서버가 적절한 응답을 하여 클라이언트 사용자에게 웹 페이지를 제공하는 서비스
3. TCP/IP 프로토콜에서는 클라이언트와 메일 서버, 메일 서버와 메일 서버 간에 이메일을 교환하려고 SMTP와 POP3, IMAP를 사용한다.
4. SNMP는 다른 네트워크 장치를 원격에서 관리할 수 있는 간단한 방법을 제공하는 인터넷 표준 프로토콜이다.
5. DHCP는 네트워크의 각 노드에 유일한 IP 주소를 자동으로 할당하고 관리하는 서비스이다.
6. 텔넷은 TCP 포트 23번을 사용하여 서비스 제공하며, 인터넷을 이용하여 내 컴퓨터에서 상대방의 컴퓨터를 원격으로 제어할 수 있도록 해주는 명령 라인 클라이언트/서버 프로그램이다.
