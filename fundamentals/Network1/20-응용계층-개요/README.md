● 20강에서는 응용계층의 기능과 다양한 서비스에 대하여 학습하였습니다.
1. 인터넷 모델 응용 계층에서는 OSI참조 모델 상위 3계층인 세션 계층, 표현 계층, 응용 계층의 역할을 담당한다.
2. TCP/IP 응용 계층에 포함되어 있는 응용 프로그램 들은 원격으로 컴퓨터 자원에 접속하는 데 사용된다.
3. 세션계층은 OSI 참조 모델의 다섯 번째 계층으로 응용 프로그램 계층 간의 통신을 제어하는 구조를 제공하기 위해 응용 프로그램 계층 사이의 접속을 설정·유지·종료하는 역할
4. 표현계층은 데이터의 보안을 위해 암호화와 복호화를 수행하고, 데이터의 효율적인 전송을 위해 데이터 압축 및 압축 해제와 코드 변환의 기능을 수행한다.
