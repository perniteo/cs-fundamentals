● 17강에서는 TCP/IP의 전송계층에서 제공하는 서비스와 전송층 프로토콜의 역할에 대하여 학습하였습니다.
1. 전송 계층은 수신지에 신뢰할 수 있는 데이터를 전송하기 위해 필요한 계층이다.
2. 전송 계층에서는 포트번호를 이용하여 전송된 데이터의 수신지가 어떤 애플리케이션인지 식별하는 기능이 있다.
3. TCP/IP 전송계층 프로토콜에는 전송 제어 프로토콜(TCP), 사용자 데이터그램 프로토콜(UDP), 스트림 제어 전송 프로토콜(SCTP)이 있다.
4. 전송 계층의 데이터 단위는 세그먼트이다.
5. 전송 계층의 데이터 헤더에는 포트 주소, 소켓 주소, 순서 번호 등이 포함된다.
6. 전송계층은 프로세스-대-프로세스 통신을 제공하며, 응용 계층 개체(실행 중인 프로그램)가 서비스를 이용하도록 메시지를 적절한 프로세스에 전달하는 책임이 있다.
