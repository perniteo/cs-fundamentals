● 18강에서는 전송층 프로토콜인 UDP, NCP, SPX 등의 개념과 기능에 대하여 학습하였습니다.
1. UDP(User Datagram Protocol)는 RFC 768 문서에 정의된 비연결 지향형 프로토콜을 말한다.
2. 사용자 데이터그램, 즉 UDP 패킷은 각각 2바이트인 4개의 필드로 만들어진 고정된 크기의 8바이트 헤더를 가지고 있다.
3. 처음 두 필드는 송신지와 목적지 포트 번호를 정의하고, 세 번째 필드는 헤더에 데이터를 더한 사용자 데이터그램의 전체 길이를 정의한다.
4. 검사합 필드는 헤더와 데이터를 포함한 전체에 대해 오류를 탐지하기 위해 사용한다.
5. UDP는 TCP에 비해 신뢰성이 낮으며, 흐름 제어 및 오류 검출 등의 기능이 없어 패킷을 빠르게 전송해야 하는 응용 계층에서 사용한다.
6. SPX는 NetWare의 연결 지향 프로토콜로 패킷 접수 통지, 흐름 제어 등 TCP와 유사한 기능
7. NCP는 NetWare 클라이언트와 서버 간의 파일 공유등 다양한 네트워크 기능을 담당한다.
