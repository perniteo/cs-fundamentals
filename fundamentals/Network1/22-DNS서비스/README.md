● 22강에서는 DNS 개념과 동작 방식에 대하여 학습하였습니다.
1. DNS의 기능은 네트워크에서 사용자가 입력한 도메인이나 호스트 이름을 IP주소로 해석해주는 TCP/IP 네트워크 서비스이다.
2. 이름을 주소로, 주소를 이름으로 맵핑시켜 주기 위하여 호스트 이름과 IP 주소간의 매핑을 담당하는 이름 공간(name space)으로 부터 신중하게 선택해야 한다.
3. DNS는 일차 서버와 이차 서버의 두 가지 서버를 지정한다.
4. 인터넷에서 도메인 이름 공간은 3가지 섹션, 즉 인버스 도메인(inverse domain), 일반 도메인(generic domain), 국가 도메인(country domain)이 있다.
5. DNS에서는 조회 메시지(Query message), 응답 메시지(Response message)메시지를 사용한다.
