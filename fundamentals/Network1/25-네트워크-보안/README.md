● 25강에서는 네트워크 보안의 개념 및 필요성과 네트워크 공격기술에 대하여 학습하였습니다.
1. 정보보안을 위한 3가지 목적은 비밀성, 무결성, 가용성 이다.
2. 보안 위협 요소에는 전송 차단, 가로채기(Interruption), 변조(Modification), 위조(Fabrication) 등이 있다.
3. 스미싱(smishing)은 문자 메시지 서비스(SMS)와 피싱(phishing)의 합성어로 SMS에 포함된 URL을 클릭하면 악성 앱이 설치되고, 개인 정보나 금융 정보 등을 탈취하는 공격
4. 랜섬웨어는 몸값,ransom 과 소프트웨어, software의 합성어로 시스템을 잠그거나 데이터를 암호화하여 사용할 수 없게 하고 이를 인질로 금전을 요구한다.
5. IP 스푸핑(IP Spoofing)은 IP 주소를 속이는 행위를 말한다. 인터넷 프로토콜인 TCP/IP의 구조적인 결함을 이용하여 사용자 시스템 권한을 획득한 후 정보를 빼가는 해킹 수법이다.
6. 스니핑(Sniffing)은 ‘코를 킁킁거리다’ 또는 ‘냄새를 맡다’는 뜻으로 네트워크를 이용하여 전송하는 데이터를 엿듣는 일종의 도청 행위이다.
