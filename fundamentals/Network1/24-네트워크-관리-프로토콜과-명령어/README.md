● 24강에서는 네트워크 관리 프로토콜과 네트워크 관리 명령어에 대하여 학습 하였습니다.
1. 관리자(manager)라 불리는 관리 지국은 SNMP 클라이언트 프로그램을 수행하는 호스트이고 에이전트라 불리는 관리 대상 지국은 SNMP 서버 프로그램을 수행하는 라우터(또는 호스트)
2. SNMP는 현재 가장 많이 사용하는 프로토콜로 구현이 쉽고 간편한 것이 장점
3. CMIP는 인증, 접근제어, 보안 로그 등 네트워크 관리 정보에 보안 체계를 갖춘 프로토콜이다.
4. Netstat 명령어는 해당 시스템에서 TCP 전송 프로토콜의 상태를 표시하고, 네트워크에서 현재 열려 있는 포트를 모두 확인할 수 있다.
5. ping 명령어는 원격의 호스트 컴퓨터, 서버 장비, 네트워크 장비와 통신이 잘 되고 있는지 확인하는 명령어이다.
6. arp 명령어는 ARP 프로토콜에서 사용하는 IP주소에서 물리적 주소로 변환된 값을 확인하고, 수정할 수 있다.
