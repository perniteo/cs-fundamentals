● 15강에서는 네트워크 계층의 인터넷 제어 메시지 프로토콜의 개념과 기능에 대하여 학습하였습니다.
1. ICMP(Internet Control Message Protocol)는 인터넷 제어 메시지 프로토콜로서, IP는 신뢰성이 없는 프로토콜이므로 ICMP는 이 단점을 보완하기 위하여 설계 되었다.
2. ICMP는 오류를 수정이 아니라 오류 내용에 관한보고 만 한다.
3. 오류 보고(error-reporting) 메시지는 다섯 가지 오류 유형을 처리하는데, 목적지 도달 불가능, 발신지 억제, 시간 경과, 매개변수 문제, 재지정이 있다.
4. 오류 조회(query)메시지는 호스트나 네트워크 관리자가 라우터나 다른 호스트로부터 특정 정보 획득 시 사용하며, 현재 에코 요청과 응답, 타임스탬프 요청과 응답 메시지만 사용됨
