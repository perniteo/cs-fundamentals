● 19강에서는 전송 층에서 전송 제어 프로토콜인 TCP의 개념과 기능에 대하여 학습하였습니다.
1. TCP(Transmission Control Protocol)는 연결 지향 형태의 신뢰성 있는 프로토콜이다.
2. TCP는 포트 번호를 이용하여 프로세스 간 통신 설정을 한다.
3. 전송 단계에서 슬라이딩 윈도우 프로토콜 이용하여 흐름 제어 메커니즘을 제공한다.
4. 전송 단계에서 응답 패킷, 시간-초과, 재전송 방식을 이용하여 오류 제어 메커니즘 제공한다.
5. TCP 세그먼트는 20 ~ 60 바이트의 TCP 헤더와 응용 프로그램으로부터 발생되는 데이터로 구성되며, 헤더는 기본이 20 바이트이고, 옵션을 포함하는 경우 최대 60 바이트이다.
6. 데이터를 전송하기 전에 연결을 확립하기 위해 패킷 요청을 세 번 교환하는 것을 3-way 핸드셰이킹이라고 한다.
